Release Notes

HELIOS Parse / View 1.3.0, released 2026-10-21. Code developed by Dmitrii Bespalov at European XFEL.

Documentation Index User Guide Developer Guide README

Why 1.3.0

This release adds an optional native XCOM 3.1 provider to the experimental Transmission workflow while keeping covered calculations on the fast, in-process cold-XCOM tables.

Highlights in this release

  • optional native XCOM 3.1 subprocess support for neutral elements and mixtures through Z=100
  • table-first calculations for covered requests, with native fallback for supported requests outside the table domain
  • bounded native request batching, result caching, cancellation, and subprocess cleanup
  • clearer Transmission units, provider status, and applicability guidance in the interface
  • cross-platform native packaging hooks; public release packages retain the lookup tables and omit native payloads pending redistribution review
  • documented table provenance, native provider behavior, and scientific limits

The 1.3.0 bundle intentionally omits tests, internal audit and validation reports, old release outputs, legacy shadow source files, the vendor XCOM archive, and compiled native payloads. Experimental Transmission/XCOM support remains behind development flags.

Known validation limits

  • XCOM remains a neutral-atom cold baseline. The interpolation tolerance does not establish physical accuracy for warm dense matter or near-edge chemical structure.
  • The native Orca screen-reader and keyboard walkthrough remains unverified. Automated accessibility checks and Windows UI checks pass.
  • Performance comparisons found no repeatable median regression above the review threshold, but speedup measurements for several scenarios remain inconclusive.
