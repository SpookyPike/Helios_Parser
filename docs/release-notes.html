Release Notes

HELIOS Parse / View 1.2.0, released 2026-10-20. Code developed by Dmitrii Bespalov at European XFEL.

Documentation Index User Guide Developer Guide README

Why 1.2.0

This release brings the parser, HDF5 conversion, analysis services, desktop interface, and packaging through a broad reliability and usability update. It also documents the performance checks used to evaluate the changes.

Highlights in this release

  • safer LOG/BPF conversion with atomic output publication and clearer corruption versus truncation handling
  • versioned H5D schema 2.1 pressure semantics, explicit run status, and corrected cumulative source-energy accounting
  • revision-aware cache retirement, bounded cache ownership, and demand-driven derived data loading
  • independent analysis-module availability with specific missing-input explanations
  • improved BPF workflows, accessibility names, window layouts, theme updates, and packaged scientific resources
  • targeted performance regression tests and reproducible before/after benchmark tooling

Changelog

1.2.0

  • made conversion publication atomic and strengthened LOG/BPF numeric, marker, partial-record, and companion validation
  • recorded structural run completeness separately from simulation completion evidence
  • defined plasma versus total pressure aliases in H5D schema 2.1 and corrected cumulative-source units and budget coverage
  • added stable run revisions, stale-task rejection, retired-cache protection, geometry refill, and byte-budgeted cache retention
  • made derived modules report independent availability and selected-weighting prerequisites
  • improved reader metadata fan-out, viewer request coalescing, and demand-driven optional fields
  • added BPF-aware desktop routing, clearer accessibility and layout behavior, live theme updates, and bundled scientific resources
  • added repeatable performance tests and benchmark comparison evidence; timing results are documented without overstating inconclusive speedups
  • updated Windows, Debian, Linux portable, and source-bundle release metadata

1.1.3

  • changed field-browser metadata labels to suppress internal legacy/unknown fallbacks for ordinary HDF5 files
  • renamed the fallback status presentation from legacy to parsed where it is still shown in filters/tooltips
  • made field-list foreground colors theme-aware so dark mode remains readable
  • rebuilt the Windows portable parser/viewer executable artifact

1.1.2

  • added PyInstaller-based Windows portable runtime build and validation scripts
  • added Debian package builder with package metadata, system launchers, desktop entry, icon, sample data, and schema-2.0 example
  • added Linux portable tarball fallback and documented why AppImage is not produced by this Windows-based workflow
  • included SVG UI icons in package data so installed/packaged viewer resources are complete
  • documented build and usage instructions for runtime artifacts

1.1.1

  • fixed viewer plotting for time,frequency, time,node, time,boundary, and time,bpf_record_value fields
  • added source/status/axes field filters and alias visibility control for rich BPF inventories
  • kept unsupported higher-dimensional fields user-facing and non-fatal
  • cleaned CLI parse-failure messaging for malformed or truncated inputs
  • moved smoke and BPF tests onto tracked fixtures so clean clones remain reproducible
  • added tracked sample inputs and a generated schema-2.0 BPF example to the release bundle

1.1.0

  • added production BPF parser integration and BPF-primary HDF5 conversion
  • added transparent `.log` / `.bpf` input routing, including LOG+BPF, LOG-only, and BPF-only modes
  • added dynamic reader field discovery and schema-aware plotting-mode selection
  • validated BPF record 14 as padded radiation energy density and derived LOG-compatible radiation pressure/energy aliases
  • schema 2.1 separates plasma and total pressure; legacy pressure aliases total pressure
  • documented final BPF field-forensics outcomes and confidence levels

1.0.1

  • added backend feature gating for production-hidden physics modules
  • added explicit HDF5 snapshot and trace accessors for targeted viewer reads
  • vectorized the spectroscopy thermal-width time-series calculation
  • cleaned release packaging and added bundle-content validation

1.0.0

  • production GUI hides Plasmon/XRTS and Transmission unless HELIOS_DEV_MODE=1 or HELIOS_ENABLE_EXPERIMENTAL=1 is set
  • kept production-visible Shock, WaveFront, Preheat, XRD, and Spectroscopy workflows with lightweight physical sanity checks
  • rebuilt release metadata and examples for the 1.0 line

0.9.1

  • documented model-aware Transmission with explicit mode selection and selected-result traces
  • documented the XCOM seam, canonical material resolution from parsed EOS/opacity metadata, and precomputed cold-XCOM fallback-table behavior
  • documented expanded plasmon/XRTS quick-look modes and warning semantics for degenerate, non-collective, or out-of-domain states
  • updated bundle-facing quick-start text and release metadata
  • rebuilt the release archive from the current repository state

0.9.0

  • major documentation expansion for users, developers, maintainers, and collaborators
  • release metadata and attribution added to About text, README, docs, and package metadata
  • shareable Windows/Linux source bundle with launch/bootstrap scripts and included demo HDF5 runs
  • current WaveFront, interface-event, and Preheat behavior documented with screenshots and interpretation notes

Bundle contents

  • source tree under src/
  • updated documentation under docs/
  • selected packaging script under scripts/
  • Windows launcher: Run_HELIOS_Analyzer.ps1
  • Linux launcher: run_helios_analyzer.sh
  • top-level quick start: README_FIRST.md
  • selected demo HDF5 examples under examples/

The 1.2.0 bundle intentionally omits tests, internal audit and validation reports, old release outputs, and legacy shadow source files. Experimental Transmission/XCOM support remains in source behind development flags.
